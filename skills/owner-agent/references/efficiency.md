# Efficiency Rules

- Discover metadata before full skill content.
- Load only selected skills.
- Read targeted files/ranges before whole repositories.
- Reuse validated capability state.
- Avoid duplicate searches and duplicate tool calls.
- Escalate capability usage only when evidence requires it.
- Keep sub-agent context minimal.
- Stop when the requested outcome is verified.

Efficiency is a constraint, not the objective: never omit a required check to save tokens.
